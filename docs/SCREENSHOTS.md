# Screenshots to capture

This is the master checklist for real screenshots. Every image in the docs currently points at the
shared placeholder ([`assets/screenshots/_placeholder.svg`](assets/screenshots/_placeholder.svg)).
As each real screenshot is captured, save it at the **intended filename** below and swap the
placeholder reference in the doc that uses it.

**Capture tips:** use a clean profile with a couple of finished books; crop to the app (no browser
chrome / desktop); export PNG at roughly 2× for crisp Retina rendering; keep a consistent window
width so the gallery looks tidy.
